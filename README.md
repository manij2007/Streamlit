# Streamlit

This repository contains my projects, examples, and experiments built with **Streamlit**.

## What is Streamlit?

**Streamlit** is an open-source Python framework that makes it easy to turn Python scripts into interactive web applications without requiring frontend development skills.

It is especially useful for **Data Science, Machine Learning, and AI projects**.

## Common Use Cases

- 📊 Interactive dashboards and data visualization
- 🤖 Machine Learning model deployment
- 🧠 AI and LLM applications
- 📁 File upload and data processing tools
- 💬 Chatbots and RAG applications
- 📈 Data analysis applications

## Installation

```bash
pip install streamlit
```

Run a Streamlit application with:

```bash
streamlit run app.py
```
